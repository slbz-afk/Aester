# Aester 星空修图

让用户用画面语言表达愿望，由 Agent 把愿望变成有理由、能比较、可撤回的实际调整。追求当前照片与用户意图下的深度后期效果；操作多少、参数强弱和教程顺序都不是目标。

本技能随 Aester 自然语言修图试用功能提供，可临时读取或由用户选装到 Agent 客户端。教程研读、算子正确、摄影缺陷检查、用户审美认可分别记录；已获认可的腾格尔试用效果不代表跨场景收益或通用美感直出完成。

## 开始一项修图

1. **先看图并保留原话。** 读原图适屏视图和与请求有关的原尺寸局部，再看参考。分别记可见事实、待验证解释、用户偏好。把参考中的冷暖、明暗主次、结构可读性转成目标；生成参考的星点、云气、山脊或纹理不能进入照片。无图像访问时可整理意图，不能声称完成视觉诊断。
2. **确认能真实执行什么。** 调用当前环境实际提供的能力查询，读取其 schema、输入域、操作语义、蒙版与产物验证状态。按 [后端接口边界](references/backend-interface.md) 适配；文档中的内部模块、GIMP 滤镜名和计划项都不是公开工具。缺能力时继续可独立完成的工作，并提出具体需求。
3. **建立比较起点。** 登记只读源、参考来源与原始意图，取得同域空配方基线及其验证回执。先有当前源/后端配置的可靠基线，才归因审美变化；有效回执可复用，无须每轮重做基线。源、颜色链或后端变化则重新核验。已有剪切、噪声、拖尾和接边缺陷单列，防止把它们算作新增或已修。
4. **确定本图真正需要的目标。** 使用 [目标与轮次记录](references/goal-loop.md) 保存区域、基线、预期关系、保护要求和达成条件，区分用户已接受的取舍、主要未达目标和可选细修。按视觉依赖选择先后；例如严重颜色/预览错误会干扰后续所有判断。简单要求只做必要调整，不强迫每图经历银河增强、缩星、降噪全套流程。

## 调整—评价闭环

- 为下一次变化写一句可检验的解释：**因为哪里存在什么问题，选何种作用域/操作改变哪种关系；用哪些局部排除什么副作用。** 按 [画面诊断与操作选择](references/diagnosis-and-operations.md) 分清亮度、色相、层次、星点竞争、噪声和蒙版问题。参数从本图的实际响应确定，不搬教程或案例数值。
- 每轮围绕一个可归因目标，必要时使用有共同理由的一组操作。新的机制或失败原因不明时先做受控对照/消融，避免同时大改蒙版、曲线、颜色和顺序。新候选始终从原始源和完整配方重放；可以继承最佳配方，不能不断处理上一张 JPEG。
- **方向正确以后，要逼近目标。** 主要目标仍未达且没有新增缺陷时，做效果幅度可辨的下一候选，或比较少量不同力度以查清有效范围；不要持续微调已接受的颜色或无关区域。每轮结束检查哪些主要目标尚未真正尝试，并把下一动作给最重要的剩余差距。具体方法见 [推进力度与分区优先级](references/goal-loop.md#推进力度与分区优先级)。
- 在相同显示、尺度和坐标下同时比较**原始基线、上一最佳候选、本轮候选**。整图判断主次与氛围，100% 局部判断纹理、星点、噪声和边界；按本轮风险补查其他尺度。逐目标标记 **未做 / 改善 / 达成 / 退化 / 证据不足**，填写证据和下一动作。工具运行成功不填“达成”。
- 硬性保护失败或不可接受的新增缺陷出现时撤回该候选，保留失败记录；下一轮从最佳候选的配方分支。轻微颗粒等代价须明确记录，按用户已有偏好与主要目标取舍，不自动否决明显改善。区域改善不能抵销关键保护失败。最佳候选是有记录的取舍，既不等于最新文件，也不等于指标最高；用户已有选择优先。
- 达成请求且必要检查通过就停止。未达成时选择能解决剩余问题或区分原因的下一动作；连续无收益先改变诊断，不继续堆参数。用 [四类限制的诊断](references/goal-loop.md#未达成时如何继续) 区分素材信号、后端能力、Agent 决策和颜色/预览错误。保留原目标；有证据的可达替代写作目标修订建议，不悄悄降低标准或冒称用户同意。

## 交付与交流

在已有授权内自主迭代，不把参数选择交给小白，也不要求每步确认。向用户报告画面改变和仍有的取舍；只有会实质改变原意且无法从现有反馈确定时才请其选择。内部保留完整账本，面向用户只展示最有用的原图/候选比较和自然语言说明。

交付当前最佳、未被否定的实际产物，附简短逐目标状态与未解决原因。JPEG、RGB16 TIFF 和可编辑工程按真实接口的导出与重开回放证据验收；技术检查不全的附件不能标成通过作品。未获用户评价时写“审美待评”，用户否定后保持失败状态。不要用“已接近大神”“恢复了参考细节”等未经证实的结论。

学习新方法、判断教程转译或更新技能时读 [证据与来源](references/evidence-and-sources.md)。只把有相应证据的方法用于相应场景，保留作者方法、当前实现和实际摄影结果之间的边界。

扩展教程、选测试素材或评价技能是否能迁移时，再读 [跨场景学习与评价](references/generalization-evaluation.md)。按拍摄来源组隔离学习、开发与留出；腾格尔参数留在案例中，不能成为通用处方。

需要空间结构、独立星层或亮迹处理时，再读 [空间尺度与图层分工](references/spatial-and-layers.md)。用到独立图层时，先验证当前源的分离与回合成；教师原型的存在不等于公共接口已支持。
