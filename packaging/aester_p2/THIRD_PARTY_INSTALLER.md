# Aester installer components

Optional natural-language retouch support downloads and runs the unmodified official GIMP 3.2.6 installer. GIMP is separately registered and remains installed after Aester removal; existing GIMP installations are never upgraded, adopted or removed. Aester owns only its registered download cache and application-local skill package. The skill is source text and ZIP for an Agent to load or the user to install; no global skill directory is written. See [retouch component provenance and lifecycle](RETOUCH-COMPONENTS.md).

Python 3.13.15 is included from the unmodified python.org embedded Windows archive, including its PSF license. Fixed wheels and the official unmodified Siril 1.4.4 portable archive are downloaded during installation. Every downloaded file comes from its official host or a listed mirror and is pinned by exact size and SHA-256, so any source yields the same bytes. By default Setup times each listed source on the first 256 KiB of one file and uses the fastest first; `/DOWNLOADSOURCE=official` uses the official URLs only (for GIMP also GIMP's own mirror opencolo.mm.fcix.net), without measuring, and follows redirects only to those hosts. Wheels come from files.pythonhosted.org or the PyPI mirrors of Tencent Cloud, Huawei Cloud, Tsinghua TUNA, USTC, BFSU, Aliyun and Nanjing University; Siril comes only from free-astro.org; the GIMP installer comes from download.gimp.org, GIMP's mirror opencolo.mm.fcix.net, or the Nanjing University, USTC and Aliyun mirrors. The full list is `DOWNLOAD_SOURCES` in `starstack/components.py`. Package licenses and metadata are retained. No GPU runtime is supplied.

When Setup lists **Siril - Aester improved build**, that optional component is included as a separately verified distribution. Its runtime, corresponding source archives, license notices and build instructions are installed together in the private component directory. Setup verifies the complete package before activation. Builds without that reviewed package do not show the option. Selecting the component makes it available under Settings > Processing backend; it does not overwrite an existing processing preference. This is an Aester modification of Siril, not an upstream Siril release or endorsement. See the component's `legal/` directory and `distribution-manifest.json` for exact versions and provenance.

The installer does not bundle the nox ONNX model. On first launch the user may opt in to preparing the component, using an explicitly configured download URL or an existing verified local model. The production download URL is currently unconfigured. The optional nox model is **our ONNX conversion of Christopher Harvey's trained nox model**, not an upstream ONNX release. The author's [README license section](https://github.com/charvey2718/nox#license) expressly applies MIT to code and trained weights. The complete MIT notice, author README snapshot and conversion evidence accompany this installation. Source PB: [v1.1.0](https://github.com/charvey2718/nox/releases/download/v1.1.0/noxGeneratorColor.pb), SHA256 `d54bdca728d1d6db0b3eef41d4187d327909d1ec5cd2a71485bfa9d7924ba546`; converted ONNX SHA256 `72451a04e90750f6dd42879415d2f5a0278e8e39cbce5664f246095a94e6752e`. Conversion used tf2onnx 1.16.1, opset 17. Seven recorded comparison inputs differed by at most one 16-bit display code after product quantization; this is finite validation, not an all-input equivalence proof. CPU ONNX Runtime is separately obtained from PyPI.

The author identifies SIDD and RENOIR as training backgrounds. SIDD publishes an MIT notice; this review could not establish RENOIR's separate dataset terms. The explicit model MIT grant is the basis for this optional component. Full provenance and commercial rights-chain due diligence are not claimed complete. The dataset itself is not included, fetched or used for training here. nox can leave halos or remove compact nebulosity; installing it does not automatically enable star reduction.

The application bundles four SIL Open Font License 1.1 font families, unmodified: Noto Sans SC (Regular, Medium), IBM Plex Sans (Regular, Medium, SemiBold) and IBM Plex Mono (Regular, Medium), with Reserved Font Name "Plex", and LXGW WenKai Lite (Regular). They are registered for Aester's own process only and are not installed into Windows. Their licence texts (`OFL-*.txt`) and the source, size and SHA256 record `FONTS.json` are installed beside them in `aester_desktop/assets/fonts`; the installer build refuses any missing or altered font file.

Inno Setup 6.7.3 creates this installer. Its included license grants commercial use subject to preserved notices; the publisher also requests purchase of a commercial license. See [Inno Setup](https://jrsoftware.org/) and the included `Inno-LICENSE.txt`. This Aester installer and launcher are not code-signed; the compiler's upstream signature does not sign Aester.

Uninstall removes installed application files, shortcuts and this installation's exclusively owned components and registered downloads, including an optional improved Siril runtime and its corresponding source package. Original photographs, exported images and unknown or shared files are kept. Job cache files and preferences are kept by default; only verified safe cache files and known preferences may be explicitly selected for removal. No PATH, global Python or machine-wide environment settings are changed.

Aester is free software in two parts: the processing engine (StarStack: engine, command line, MCP server; Apache-2.0) and the desktop application (GPL-3.0-or-later); both ship with their source. The LGPL-3.0, GPL-3.0 and Apache-2.0 texts for the third-party components are installed in this folder (LGPL-3.0.txt, GPL-3.0.txt, flatbuffers-Apache-2.0.txt).
