# Security / 安全问题

Please do not report security problems in public issues.

- **Preferred**: use GitHub's "Report a vulnerability" button on the [Security tab](https://github.com/slbz-afk/Aester/security) of this repository. Only the maintainer can see the report.
- **Or e-mail**: aester-star-stacker@outlook.com, with "Aester security" in the subject.

Please include:

- the affected version;
- what an attacker could do;
- the steps to reproduce.

You will get a reply when the report has been read. Aester is maintained by one person, so fixes are made as time allows, and no fixed response time is promised.

Aester runs locally and does not upload photographs. The most relevant areas are:

- the installer and its downloads;
- the local MCP server;
- the handling of untrusted files, such as RAW, FITS, TIFF or project files.
