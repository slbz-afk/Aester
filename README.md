# Aester · 让星空自然呈现

Aester 是在 Windows 本机运行的星野摄影后期软件。

- **自动完成**：把同一机位连拍的一组相机 RAW 交给它，它会完成堆栈、天空与地景分开对齐合成、降噪和出片。
- **可选效果**：流星加回、星点整理、银河增强和分层导出，按需打开。
- **AI 助手**：可以让支持 MCP 的 AI 助手操作 Aester，或调用 GIMP 按自然语言精修。

Aester 完整免费、开源。支持开发完全自愿，不解锁任何功能。

## 怎么用

界面按 01–06 六个阶段排列：

1. **素材**：添加同一机位、同一构图的一组连拍 RAW，至少 3 张。原片只读，不会被改动。
2. **首帧**：用第一张照片生成预览，按机型套用相机观感。可调冷暖、绿/洋红色调和曝光，预览与成片用同一套颜色处理。
3. **分区**：画出地景边界，有银河时拖出银河椭圆。天空随时间移动、地景不动，所以两者分开对齐。不画地景就按全天空处理。
4. **合成**：在后台处理，显示阶段、进度和剩余时间。可以停止，中断后可以续跑。
5. **成片**：每个任务得到三份图像：
   - 直接分享的 JPEG；
   - 可继续编辑的 16 位 TIFF；
   - 供深度后期的 32 位浮点线性母版。
6. **让 Agent 帮你修**：生成给 AI 助手的提示词。助手通过 Aester 的 MCP 读取成片，再用 GIMP 按你的描述做局部修图，修好的版本另存。

**可选效果，默认都关闭：**

- **保留流星等亮迹**：先完成基础成片，再加回测量可靠的流星，另存为含亮迹版本。可以在复核界面逐条改判。
- **整理星点**：需要可选的 nox 组件。把星点从背景分离，按 0–100% 减弱星点，并可另存无星图和星点层。
  **1.0.0-rc.1 暂不提供 nox 下载**：这个第三方模型的训练数据权利还在核查，核清前这项功能暂时用不了。
- **突出银河**：只在画定的银河椭圆内做渐变增强。

完整说明见[使用指南](docs/USER_GUIDE.md)。

## 下载与安装

到 [Releases](https://github.com/slbz-afk/Aester/releases) 下载 `Aester-…-Setup.exe`，并核对页面上的 SHA-256 校验值。

- **系统**：Windows 10 / 11，64 位。按当前用户安装，不需要管理员权限。
- **安装时需要联网**：
  - 基础组件约 290 MB，安装器会从官方服务器或国内镜像中选最快的一处下载，每个文件都校验 SHA-256；
  - 装好后可以完全离线使用。
- **磁盘**：
  - 程序和组件约 1–2 GB；
  - 处理时另需缓存，48 张 4500 万像素 RAW 一次约 50–80 GB；
  - 缓存可以在“设置 → 作品与缓存”里按任务清理。
- **内存**：建议 16 GB 以上。
- **未签名提示**：安装包没有代码签名，Windows 可能提示“已保护你的电脑”。确认文件来自本页面、校验值一致后，点“更多信息 → 仍要运行”。

## 支持的相机

- **完整验收**：Nikon Z 8 和 ZWO Seestar S30 Pro 用真实连拍序列走通了完整流程。
- **能解码**：Sony、Nikon、Canon 的二十多款机身能解码，大多带有默认相机观感，但没有用真实序列验收。
- **其他机型**：取决于 LibRaw 0.22.1 能否解码。

完整列表可以运行 `starstack devices` 查看。欢迎用你的相机试用并反馈。

## 已知限制

- **不保证所有场景都能直出满意画质**：云、遮挡、风动的树枝、强光害和彩边仍然困难；智能望远镜深空只做了基础适配。
- **整理星点暂不可用**：见上文。以后提供时，它也只是算法估计，亮星附近可能留有残晕。
- **流星加回只针对测量可靠的流星**：其他亮迹留给人工复核。
- **修图需要另装软件**：要有 GIMP 3.2.6，以及你自己的、支持 MCP 和看图的 AI 助手。
- **缺少实测**：其他电脑和高 DPI 多显示器上的实测还很少，遇到问题请[反馈](https://github.com/slbz-afk/Aester/issues)。

## 让 AI 助手使用 Aester

Aester 自带 MCP 服务，提供导入、分区、合成、亮迹复核、星点、银河、导出和修图等工具。首次启动的欢迎页可以复制客户端配置，并验证连接。详见[使用指南](docs/USER_GUIDE.md#mcp)。
