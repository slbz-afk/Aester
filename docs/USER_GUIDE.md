# Aester · 开始创作

## 安装与第一次启动

运行 Aester 安装器，选择安装位置。安装过程中会准备基础环境和 Siril；需要联网，下载中断后可重试，已校验的文件会复用。安装器先测速，从官方服务器或所列镜像中较快的一处下载，每个文件都按 SHA-256 校验。
希望使用“整理星点”或无星图层时，勾选可选的 **nox 去星组件**；它默认不勾选，安装后也不会自动开启照片效果。
如果先体验基本合成，可以之后重新运行安装器勾选 nox，或在“设置 → 组件与提示词管理”选择本项目已核验的转换模型。更换运行环境后，先保存编辑项目，再按提示重新启动。

欢迎页可以选择“直接开始”或“连接 AI 助手”。没有大模型也能使用全部已安装的本地处理功能；欢迎页可从帮助菜单再次打开。
“设置 → 外观”可选择**深色或浅色**，下次启动会记住选择；同一菜单还有“夜视模式”和“画面四周”，见下文“看片环境与界面标记”。深色与浅色只改变界面，照片预览、分区颜色和最终成图保持原样。

“设置 → 语言”可选择 **English** 或 **中文**。保存编辑项目后重新启动 Aester，语言选择会在下次启动时应用并记住。语言只改变界面、帮助和错误消息的文字，不改变照片、配方、文件路径或 MCP 协议键。

<a name="start"></a>

## 第一次用，只需四步

窗口顶部的阶段条依次是 01 素材、02 首帧、03 分区、04 合成、05 成片，末端的“让 Agent 帮你修”是 06 精修。阶段条只显示进度并提供快捷入口，不切换页面：可用的节点可以点击，暂不可用时悬停会说明原因。
左侧是看片区；右栏按操作顺序排列 ① 分区、② 调色、③ 可选效果，底部固定“作品保存位置”和“开始合成 / 停止”。窗口最下方的读数条显示阶段、进度、百分比和完整消息，“详情”打开处理记录。

1. **添加照片**：选同一机位、同一构图的一组连拍 RAW。可以多选、拖入窗口，或用看片区上方的“添加照片”“移除所选”，点“清空素材”一次清空列表（不删除原片）；至少三张才能合成，单张也能预览。画面下方的照片列表中第一张（首帧）用于颜色参考；上方每个小点是一张照片，带环的是首帧。
2. **标记需要处理的范围**：点右栏 ① 分区的“标记天空 / 地景 / 银河”。有地景就画边界，有银河就画椭圆。未画地景按全天空处理；不画银河便不做银河增强。无需重复确认。
3. **调整颜色、选择效果**：右栏 ② 调色的滑块改变冷暖、绿／洋红色调和曝光；③ 可选效果里的三个效果均默认关闭。调色时使用小代理快速预览，停止拖动后自动补上清晰预览。
4. **开始合成**：点右栏底部的“开始合成”。完成后点视图行的“打开作品目录”（也在“文件”菜单中），取得母版、16位成片和 JPEG。

照片在本机处理，原片不改动。请先用少量素材试跑；不同夜晚、重新构图和明显不同曝光不要混在一起。

<a name="colors"></a>

## 照片方向不对时

导入时按首张照片记录的拍摄方向显示，同一组照片统一使用该方向。画面下方的“左转 90°”“右转 90°”可整组手动修正；“恢复拍摄方向”回到首帧记录的方向。RAW 与 DNG 都可以调整，不改原片，不裁切，也不插值。

请先确定方向，再画地景和银河。绘制后更改方向会清除旧分区，并提示重新标记；旋转完成后才可开始合成。方向会保存到编辑项目，并应用到最终母版、TIFF 和 JPEG。旧项目保持原方向，避免已有分区错位。

## 颜色怎么调

在右栏 ② 调色中，冷暖向右偏暖，色调向右偏洋红；曝光以 EV 表示，向右更亮。也可在滑块旁的数值框输入数值，按 Enter 或离开输入框即应用；曝光以 0.1 EV 为一档。鼠标滚轮只滚动右栏，不会改变滑块和数值框。双击滑块恢复为 0；标题行的“重置调整”恢复拍摄时白平衡与默认影调。
冷暖／色调是相对调整，不是测量出的色温。首帧预览和最终成片共用颜色处理逻辑及所选第一张照片的颜色参考；天空和地景一起调整。

视图行的“相机观感”标签显示首帧预览使用的观感：机身、借用的观感表和强度，例如“相机观感 · α7R V · 借 α7 IV 表 · 0.50”；没有观感时显示“相机观感 · 无”。它只影响预览与成片的颜色风格，原片不改动。
合成后首帧预览会被清空。需要再看时，点阶段条的“02 首帧”或视图行的“刷新首帧预览”，按当前照片与颜色重新生成。

单帧比堆栈更嘈杂，缩小预览也不能展示每颗星的细节，因此不会与成片逐像素相同。
FITS 深空素材沿用基础显色，目前不支持这些相机颜色滑块；不要把它当作相机 RAW 校色。

- **JPEG**：直接观看和分享。
- **16位成片 TIFF**：已经调好显示影调，可在常用修图软件中继续编辑。
- **线性母版 TIFF**：保留更多后期空间。看起来很暗是正常的，需要支持线性图像的后期方式；滑块美化不会改写它。

<a name="viewing"></a>

## 看片环境与界面标记

**画面四周**：“设置 → 外观 → 画面四周”可选“玄 · 默认”“中灰评估”“纯黑 · 仅观赏”。画面下方的“中灰”按钮可直接切换中灰评估：画面四周换成中灰，便于导出前评估亮度与对比。纯黑四周会让画面显得更亮，只适合观赏。四周颜色只改显示，不改照片。

**夜视模式**：在野外保护暗适应时，从“设置 → 外观 → 夜视模式”、画面下方的“夜视”按钮或快捷键 Ctrl+Alt+N 开启，再按一次关闭。整个界面改为纯红，画面以红色单通道显示，左上角常驻“不可判色”。夜视只改变显示，不能用来判断颜色；导出的照片不受影响。

**来源标记**：界面用小圆点标明谁做的决定。朱色实心点表示由你决定，缃色（米黄）实心点表示 Agent 参与，空心圆表示算法给出的建议、尚无人确认。你在标记画面中保存分区后，右栏 ① 分区标题旁会出现朱色点和印章“人定”；Agent 通过 MCP 绘制的分区只显示缃色点，不加印章。“让 Agent 帮你修”旁的缃色点表示这一步由外部 Agent 完成；亮迹复核中“人工改判”和“Agent 草稿改判”也分别标出。

**二十八宿**：处理进行中，读数条左端、当前阶段节点（合成时为 04，生成首帧时为 02）和空白看片区上的 28 条固定短线依次明暗流转，表示软件正在工作。关闭 Windows 动画效果时改为静止显示，窗口最小化时暂停；夜视模式下为红色。

错误消息在读数条中以朱色文字显示，并配一个错误图标。

<a name="masks"></a>

## 天空与地景

星空会随着时间移动，地景通常不动，所以需要分开对齐。点击右栏 ① 分区的“标记天空 / 地景 / 银河”：

1. 沿山脊从左到右点几个点，点击“完成地平线”。橙色区域表示地景，橙色实线是它的边界；黄色点是地平线点与手柄。
2. 房檐、树冠或器材用“补涂地景”；涂多了用“擦回天空”。可调整画笔大小，滚轮放大、中键拖动，点“适合窗口”回到整图。
3. “寻找附近边缘”给出浅蓝虚线建议，此时“接受浅蓝色边缘”按钮也以同样的浅蓝色突出显示。确认建议沿真实地平线后再点它，也可以继续使用原线。它只寻找附近明暗变化，不能判断什么是山脊。
4. 点“使用这些分区”。绘制即生效，软件会自行保存原尺寸区域，不需要制作额外文件。

撤销／重做可退回修改；旧的外部灰度PNG仍可从设置菜单载入。“清除地景”恢复全天空。笔刷圆圈显示当前实际覆盖范围，并随放大缩小变化。
有尚未使用的绘制时，取消、按 Esc 或关闭窗口会先询问：“使用这些分区”“放弃更改”或“继续编辑”。
选择其他素材或处理后端后，旧分区需要重新确认，避免错用到另一张图。

先画大致轮廓，再放大检查边缘。静态分区不能修复风动树叶、复杂透空或大幅移动的云；低成本边缘柔化也不能保证消除这些接边。

<a name="stars"></a>

## 整理星点

星星太密时，在右栏 ③ 可选效果中勾选“整理星点”。默认采用软件建议，也可关闭自动建议，手动设定0–100%。
0%保留原样；中段主要压低中低亮度星；高强度会减弱亮星，100%表示移除当前后端分离出的整个星层。
建议值是可改的审美起点；无星背景是否干净仍取决于后端，亮星附近可能有残晕。

此功能需要配置去星模型。安装或选择模型不会自动开启；没有模型时仍可正常堆栈出图。
绘制银河范围后，可设置“银河相对偏移”。例如背景80%、偏移−20%，银河为60%；负值让银河内保留更多星点。未绘制银河时该选项不生效。启用整理星点后，展示和交付的成片就是整理后的版本。

需要分层后期时，可再勾选“另存无星图”“另存星点层”。前者在作品文件夹另存 `starless_srgb16.tif`；后者另存分离出的全部星点：`stars_add_srgb16.tif`（相加／线性减淡）和 `stars_subtract_srgb16.tif`（相减）。无星图 − 减层 + 加层 = 整理星点之前的成片，与整理力度无关。只在纯天空中去星，地景和地平线羽化带不变。去星模型仍为试验性，无星图中可能看到小暗环、彩环或残晕。叠加星点层请用相加和相减，不要用滤色。

<a name="trails"></a>

## 保留流星等亮迹

在右栏 ③ 可选效果中勾选“保留流星等亮迹”。不需要时保持关闭，软件就不扫描、不额外生成含亮迹图片。
开启后，新任务先完成基础成片，再自动加回测量可靠的流星候选（已测量，且没有宽度、轮廓或旁带标记），另存为含亮迹版本。这是算法建议，不是身份认证；其他候选留待复核，基础成片始终保留。作品目录中会有基础成片文件夹 `delivery-<编号>` 和含亮迹文件夹 `delivery-trails-<N>kept-<编号>`。结果页签为“含亮迹 / 基础成片”，先显示含亮迹版本；说明行形如“含亮迹版本 · 已加回 N 条（算法 a / 人工 h / Agent g）· 另有 M 条待核实”。

要检查或改动，点击右栏底部“开始合成 / 停止”下方的“复核亮迹候选”：

- 在列表中选择，或在整图上点击定位；Ctrl 点选可多选，选中的亮迹带黄色圈，悬停只作高亮。下方显示实际曝光及前后曝光；没有可靠邻帧时会明确说明。
- “身份”列显示当前身份和来源点：朱色实心为你，缃色为 Agent，空心圆为算法。可按身份筛选（全部、流星、卫星、飞机、伪影、未知），“已改判”只列出改动过的候选。
- 整图上流星为绿色、卫星浅蓝、飞机橙色、伪影粉紫、未知白色；实线表示会加回，点线表示不加回。滚轮缩放，拖动或按住中键平移；双击空白处、点“适合窗口”或按 0 复原；“定位到所选”放大到所选亮迹。
- 身份（流星、卫星、飞机、伪影、未知）和处置（保留、省略）分开选择，可以批量设置。“保存草稿”方便稍后继续；“应用全部选择并出图”一次处理整批决定并另存成片，原成品保留。
- 勾选“加回后导出亮迹层”且至少保留一条亮迹时，含亮迹文件夹另存 `trails_layer_rgba16.tif`：只含已保留亮迹的透明图层，以正常模式叠在基础成片 `final_srgb16.tif` 上，正好得到含亮迹成片。它的数值是编码后的 sRGB 显示值，不是场景线性值。

新的复核按身份决定默认处置：把流星改判为其他身份会取消默认保留，改判为流星且测量可靠时默认加回；明确选择“保留”或“省略”优先于默认。未测量的候选不会加回。未知不等于卫星，也不等于流星。旧任务和旧复核沿用旧规则：只有明确选择“保留”的才加回。一条都不保留时不另建文件夹，界面会说明成片与基础版一致。
省略表示不额外加回，不能保证去掉基础堆栈本来残留的亮迹；保留也不保证恢复未测量的弱尾。曝光对照用于判断连续性，灰度显示不是最终颜色。当前新版成片复核支持已校色相机RAW；未标定FITS只保留候选记录。

<a name="milkyway"></a>

## 突出银河

在“标记天空 / 地景 / 银河”中选择“拖出银河椭圆”，粉紫双线标出银河范围。拖动中心和黄色控制点移动、缩放、旋转；方形黄点和“银河羽化”滑块调整羽化。蒙版可以超出画幅，必要时滚轮缩小到整图之外。Shift 拖动可重新画一个椭圆。
点击“使用这些分区”后，右栏 ③ 可选效果中的“突出银河”就可开启，默认60%力度，无额外确认。冬季无可见银河时不画；“清除银河”会关闭该区域的增强。绘制表示你的编辑意图，不是自动识别证据。

<a name="settings"></a>

## 处理后端

安装时可勾选 **Aester 改进构建**，用于保留堆栈中的有效零值、负值和额外高光范围。运行库、对应源码与许可证随组件一起安装，可离线使用；源码以压缩包保留在组件目录，不进入作品目录。未勾选时可重新运行安装程序补装。

“设置 → 处理后端”在 **Siril 官方构建**、**Siril · Aester 改进构建**、自选兼容构建之间选择。安装后会自动找到改进构建的路径，选择它后用于新作业；安装组件不会自动更改已有后端选择。也可从这里打开源码与许可，或导入本项目核验过的已有构建目录。官方构建仍可正常使用。
可选的 Aester 有效像素堆栈引擎基于 Siril 定制，用于区分真实零值和没有覆盖的边缘；当前需要本项目核验过的构建，不能随意换一个同名程序。
模型布局、颜色顺序等高级参数请使用该模型已经验证的配置，不要凭外观猜测。
不被当前解码器支持的压缩 RAW，可通过 **Adobe DNG Converter** 生成独立的无损 CFA DNG 工作副本。先从设置中的 Adobe 官方链接自行安装，软件会寻找常见安装位置，也可手动选程序。转换器未附在安装包中；原 RAW 保留，来源记录和 DNG 副本存工作缓存。DNG 不保证保留所有厂商私有元数据，原片仍应备份。

通常无需进入这里；安装器会准备基础后端。“设置 → 组件与提示词管理”可查看安装状态和修复组件。nox ONNX 是本项目从作者公开权重转换并核验的版本，不能任意换一个同名文件。

<a name="storage"></a>

## 保存、暂停与恢复

作品默认保存在系统图片目录下的 Aester，可在右栏底部“作品保存位置”点“选择”更改，或用“文件 → 更改保存位置…”。每个任务和复核版本单独保存一个文件夹，其中是三份基础图像：JPEG、16位成片 TIFF、浮点线性母版 TIFF，另加你要求另存的无星图、星点层或亮迹层。日志、配方和检查记录留在工作缓存，不堆积到作品文件夹。
右栏底部“JPEG 质量”滑块（60–100，默认 95）决定新任务交付的 JPEG 质量：开始合成时随任务保存，之后另存的亮迹版本沿用。可拖动、用方向键或输入数值后按 Enter，双击滑块恢复为 95。滑块下方显示每张 JPEG 的粗略大小；开启亮迹时，含亮迹版本另存一张大小相近的 JPEG。打开已有任务时，滑块显示该任务保存的质量；此时改动滑块只影响新任务。16 位 TIFF 和母版不受影响；“星点整理”和“银河局部增强”另存的 JPEG 也使用这一质量。
大型中间文件另存在本地工作缓存，默认位于当前用户的 LocalAppData / Aester / Cache。可以在“设置 → 作品与缓存”更换新任务的缓存位置，建议选择空间充足的本地 SSD；不会自动搬移旧任务。
作品目录中的文件可独立查看、编辑。新的线性母版将颜色信息和饱和保护区域保存在 TIFF 内，单独复制母版也能在 Aester 中重新显色；它不包含所有 RAW 和完整处理历史，不能替代原片备份。旧版作品仍应整体保留。
软件独立进程负责处理，关闭窗口不等于取消；需要停止时点击右栏底部的“停止”。处理进度显示在窗口底部的读数条。
失败后保留日志和已完成阶段，可从“文件”菜单继续。原片或配置已更换时，应新建任务。
“文件 → 保存编辑项目”保存照片清单、区域、颜色和效果；“打开编辑项目”可以继续修改。项目引用原片和本地预览缓存，不会复制所有照片；换电脑前需保留这些被引用文件。
“设置 → 作品与缓存”列出缓存目录中的任务，显示每个任务的占用、可释放空间和状态。48 帧任务通常留下几十 GB 缓存，其中大部分是逐帧中间文件。选中已完成的任务，点“清理所选任务的中间文件…”并确认后，只删除可由原片重建的逐帧中间文件：转换帧、配准帧、序列文件、原片副本、堆栈试验与输入帧，以及 FITS 去马赛克中间帧。作品、原片、母版、处理记录、日志和未知文件都保留，不会自动删除其他内容。
清理前会先校验作品文件夹完整；原片已移走也可以清理，但原片不在原来的位置（或大小已变）时，缓存中对应的原片副本会保留，以免删掉一张照片的最后一份。任务正在运行、正在复核亮迹或被其他窗口使用时不能清理，稍后再试即可。个别文件被其他程序占用而未删除时，列表显示“部分已清理”，关闭那个程序后可以再清理一次。
清理后作品仍可查看，也可以另存新预览、重做星点整理；但不能再复核该任务的亮迹候选，也不能恢复或重做亮迹合成，需要时从原片新建任务。旧版任务的作品保存在缓存内，仍沿用原来的保存方式，不在这里清理。

## 卸载和腾出空间

先退出 Aester、断开仍在使用它的 AI 助手，并等待后台合成结束，再从 Windows 的“已安装的应用”卸载。正在运行时，卸载会提示关闭程序后重试。

默认移除程序、这次安装专用的组件和已登记的下载文件，保留原片与作品。自己放入安装目录的文件、自备模型和无法确认归属的旧版组件会保留。

卸载时可另外勾选“清理已完成任务的处理缓存”和“清除软件偏好”，两项默认关闭。缓存清理会先验证独立作品完整，仅删除有记录的中间产物；删除后不能继续该任务的亮迹复核或恢复，需要从原片重新处理。日志、未知文件和复制到缓存中的 RAW 会保留，所以选中缓存清理也不一定清空整个文件夹。两种清理删除的文件不同：已在“作品与缓存”中清理过的任务，卸载时仍可删除它保留的母版和成片等图像中间产物。

## 自然语言修图

点阶段条末端的 **让 Agent 帮你修**（06 精修），在“你的需求”中填写希望改变和保留的内容，再复制提示词给支持看图与本地 MCP 的 Agent；“将复制给 Agent 的提示词”可先预览。尚未合成也能打开；已有成片时会带入当前作品的成片 TIFF。已加回亮迹时自动选用含亮迹版本的 TIFF，下方提示行说明当前是哪个版本；仍可手动选择另一张，手动选择会一直保留。
Aester 只准备提示词，不启动 Agent。你的 Agent 通过 Aester 的主 MCP 读取成片并修图；修好的版本另存到作品目录，原成片保留。

“参考图（可选）”可放一张你喜欢的效果图，并选择来源：他人作品、我自己的作品或 AI 生成图。请把它放在助手可读取的素材范围或作品保存位置内，否则 Agent 可能打不开，对话框会提示。Agent 只借鉴它的观感与目标，例如冷暖、影调取舍、银河层次和结构，不会复制参考图的像素。未提供参考图时，Agent 会先问你一次。

1. 在 **设置 → 组件与提示词管理** 勾选要准备的 GIMP 和修图技能包，或选择已有 GIMP console 程序，再点突出显示的“按所选组件，生成给助手的提示词”：它先准备勾选的组件（勾选 GIMP 时，本机已有就直接使用，否则下载 GIMP 官方安装程序，来自官方网站或所列镜像中较快的一处，按 SHA-256 校验），再生成提示词并复制；什么都不勾选时只生成并复制提示词。按钮下方的提示行列出将要准备的内容。GIMP 是自然语言修图的本地执行组件；官方安装程序独立管理它，卸载 Aester 会保留 GIMP。基础合成不需要它。
2. 建议同时准备 **Aester 修图技能包**。把提示词列出的技能入口交给 Agent 读取，或按所用客户端的方式安装。技能提供看图、局部检查和候选比较的方法；不安装技能也能复制提示词和调用 MCP。Aester 不会自动写入客户端技能目录。
3. 从 **连接 AI 助手** 复制配置，添加到客户端后验证连接。修图提示词包含本机技能入口、可用组件信息、所选照片和你的要求；复制本身不会启动 Agent，也不表示客户端已经连接。
4. 先让 Agent 检查图像与能力，再提出小步调整、展示整图和相同位置的 100% 局部。描述具体反馈，例如“银河层次更清楚，保留气辉，地景再亮一点；亮星不要更粗”。挑选满意候选后，另存 JPEG、TIFF 与可编辑 XCF，原图保留。

当前入口使用带明确 sRGB 色彩描述的 16 位 RGB 成片 TIFF。RAW、线性母版或不明颜色域需先转换为明确的显示图像。普通 TIFF 不会自动获得独立星层、银河和亮迹图层；这些处理需要适配的真实分层资料。当前星形、降噪和复杂边缘仍有局限，工程回放通过不代表照片已达到你的审美目标。

照片由本地执行器处理；外部 Agent 客户端是否向模型服务发送图像，取决于客户端、你的请求与授权。技能包不包含练习照片。

## 让 AI 帮我做（MCP）

GUI 与 MCP 使用相同的处理核心和参数，不必学两套摄影流程。打开“设置 → 连接 AI 助手”，选择允许助手读取的素材范围，然后复制配置或给助手的提示词。
“检测本机服务”会真实启动服务并检查工具调用；检测成功表示本机 Aester 可响应，不表示已连接你使用的 Agent 客户端。把配置加入客户端后，请让助手验证连接。Aester 不需要模型 API 密钥，也不会自动改动客户端配置。

可以直接给 Agent 以下提示词：

> 用我选出的这几张星空照片合成。只处理我列出的文件，首张作颜色参考，生成线性母版、16位成片和 JPEG。亮迹保护和星点整理先关闭。开始前告诉我是否还缺天空／地景分区，完成后给我图片和保存位置。

> 这组照片全是天空，没有地景。使用建议强度整理星点；模型未配置时先告诉我缺什么。色彩稍暖、曝光增加0.3 EV。不要增强未确认的银河。

> 在首帧预览上标出天空和地景，给我看区域；我确认后开始。请在可见银河上绘制可移动、旋转和羽化的椭圆并预览；绘制后即可开启增强。不确定或没有银河时不绘制。

> 扫描这组照片中的亮迹。先给我基础成片和候选，未知单独列出。查看本帧及相邻曝光，保存我的批量保留／省略选择，然后生成新版本，保留原成片。

给接入者：主要入口为 `get_help`、`inspect_sources`、`prepare_reference`、`submit_workflow` 和 `workflow_status`。
提交支持明确 `input_files` 清单；`trails_enabled`、`stars_enabled` 默认均为 false。
区域优先使用 `draw_regions`，可直接画地平线、地景笔触和银河椭圆并返回叠色预览；也可用 `create_regions`／`update_regions`／`get_regions`。`preview_regions` 生成与GUI一致的叠色检查图（橙色为地景，粉紫双线为银河椭圆），默认只返回路径，明确设置 `include_image=true` 才向当前MCP客户端返回小尺寸图片（须符合用户图片访问授权）。预览本身不会开启银河；显式绘制记录实际编辑者来源并启用该选区，无额外人工确认开关。返回路径交给 `submit_workflow(regions_path=...)`；亮迹使用 `open_trail_review`、`trail_candidate_context`、`save_trail_review`、`apply_trail_review`。保存和应用都带刚读取的草稿版本，以免覆盖其他窗口。MCP绘制记录来源为Agent，界面以缃色点标出、不加“人定”印章，不冒充人工判断。`import_photos` 可使用宿主已配置的 Adobe 转换器处理不兼容 RAW；返回的明确 DNG 清单可直接继续预览、分区和合成，不能扫描其他缓存素材。
`prepare_reference` 会返回 `image_rotation`（相对未旋转解码像素的顺时针总角度）。方向不对时调用 `rotate_reference(reference_dir, image_rotation=0/90/180/270)`，用返回的新参考重新绘制分区；随后提交同方向，或让 `regions_path` 自动绑定。它不会修改原片或旧分区。仅传旧的独立 PNG 蒙版时保留原方向；要旋转须显式传 `image_rotation`。
`color_adjustments` 包含 `warmth`、`tint`（−100至100）、`exposure_ev`（−4至4）；零值为默认。
`jpeg_quality`（60至100的整数）设定本任务全部 JPEG 的质量（4:4:4 色度），冻结在提交中，之后的亮迹版本沿用；省略时各 JPEG 保持原有编码。界面总会发送“JPEG 质量”滑块的当前值。
宿主限定素材／作品／缓存路径，并配置引擎及模型。生成的配置使用 `STARSTACK_INPUT_ROOT`、`STARSTACK_OUTPUT_ROOT`、`STARSTACK_CACHE_ROOT`；工具调用不能扩大这些根目录。旧配置未指定缓存根时保持原保存布局。每次提交保留返回的任务位置；重试使用同一提交标识，避免重复大作业。
`inspect_workflow_cache(workflow_dir)` 只读报告已完成任务可释放的中间文件、保留部分和不能清理的原因；检查不要求原片仍在原位置；删除只能由用户在“设置 → 作品与缓存”确认，MCP 不提供删除工具。清理过的任务在 `workflow_status` 中带 `cache_cleaned`。
现有进阶工具仍保留，但不应要求入门用户理解内部产物名称。本机预览不会因此自动上传给外部模型。

## 当前边界

Aester 是暂定名称，目前为开发版。主要实测是 Nikon Z8 星野和一组 Seestar 深空序列；其他型号能解码不代表已通过画质验收。
复杂地景接边、通用流星身份、成熟无星作品及全自动银河定位尚未全部验收。目前提供 Windows 安装候选版，仍需在其他电脑上验证安装和真实素材。
如遇失败，窗口底部读数条会显示完整消息，点“详情”查看处理记录；反馈时附素材场景、所选选项、任务目录及异常位置。
